xlsxjs responsive mode

Left: default — the sheet's <section> lays out at its natural width; horizontal overflow lives on the outer viewport. Right: responsive: true — the section itself becomes an overflow-x: auto scroll container with sticky first column & header row.

Default: responsive: false

Section width = table width. Scroll the pane itself to see columns to the right.

Responsive: responsive: true

Section caps at 100%; horizontal scroll lives inside the section, first column & header row stay pinned.
